# Contexte des joueurs

Ce fichier est injecté dans chaque prompt LLM.
Remplis les infos pour chaque joueur — surnoms, vannes, contexte perso, style de jeu.
Le LLM s'en sert pour personnaliser ses messages.

---

## Exemple de format

```
**NomRiot** (alias: surnom_discord)
- Rôle principal : Mid
- Champion signature : Zed, Yasuo
- Running jokes : perd toujours en Gold, achète jamais de pink wards
- Contexte : s'énerve dès la 5e minute, flame le jungler en permanence
```
